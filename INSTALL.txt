نصب روی DeepSeek Harness (dsh)

1) کل پوشه را دست‌نخورده کپی کن. index.js به saver-core.js و persist.js وابسته است
   و بدون آن‌ها لود نمی‌شود. حداقل این‌ها باید با هم باشند:

   package.json
   cordis.patch.yml
   index.js
   compress.js
   saver-core.js
   persist.js
   rtk/**          (کل پوشه، شامل rtk/filters و rtk/windowsPath.js)
   docs/**         (اختیاری — AGENTS.md داخل پکیج)

2) از ترمینال:

   dsh plugin --profile web add "/مسیر/کامل/dsh-local-saver"

   اگر dsh روی PATH نیست:

   npx @deepseek-ai/dsh plugin --profile web add "/مسیر/کامل/dsh-local-saver"

3) هارنس را کامل ببند و دوباره باز کن.

4) کلید DeepSeek را عوض نکن. همان Settings → Models رسمی بماند.
   این ماژول کلید را نمی‌خواند و به جایی نمی‌فرستد.

5) تست: در چت بگو «local_saver_stats را صدا بزن».
   باید اعداد calls / chars_saved بیاید.

اگر پلاگین در لیست باندل نیامد، package.json باید فیلد زیر را داشته باشد
(همین پوشه دارد):

  "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
