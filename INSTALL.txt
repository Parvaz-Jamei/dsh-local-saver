نصب روی DeepSeek Harness (dsh) — نسخه 0.6.2

1) کل پوشه را دست‌نخورده کپی کن. حداقل این‌ها باید با هم باشند:

   package.json
   cordis.patch.yml
   index.js
   compress.js
   saver-core.js
   persist.js
   rtk/**          (شامل rtk/comments و rtk/filters)

2) از ترمینال:

   dsh plugin --profile web add "github:Parvaz-Jamei/dsh-local-saver"

   یا مسیر محلی:

   dsh plugin --profile web add "/مسیر/کامل/dsh-local-saver"

   اگر dsh روی PATH نیست:

   npx @deepseek-ai/dsh plugin --profile web add "/مسیر/کامل/dsh-local-saver"

3) هارنس را کامل ببند و دوباره باز کن.

4) کلید DeepSeek را عوض نکن. این ماژول کلید را نمی‌خواند و به جایی نمی‌فرستد.

5) تست هوک:

   Use local_saver_stats

   باید hook_attached=true باشد.

6) حذف کامنت پیش‌فرض خاموش است. اول preview:

   Use local_saver_toggle with strip_comments preview
   Use local_saver_stats

   اگر اعداد seen/removed/kept درست بود:

   Use local_saver_toggle with strip_comments on

اگر پلاگین در لیست باندل نیامد، package.json باید این را داشته باشد:

  "dsh": { "bundle": { "patch": "./cordis.patch.yml" } }
